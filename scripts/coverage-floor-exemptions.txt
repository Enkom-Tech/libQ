# Published crates with no coverage floor
# =======================================
# Enforced by scripts/ci_guard_coverage_floors.py.
#
# Format:  <crate> | <reason>
#
# This file is a RECORD OF A GAP, not a set of approvals. Every line is a published crate
# that no workflow measures against a coverage threshold, so its coverage can fall to zero
# without any CI run noticing.
#
# History: the 2026-08-08 baseline was 77 published crates, 46 gated names, 31 unmeasured.
# 23 of those 31 were then measured and gated in coverage.yml's `extended-coverage` job, at
# floors set ~5 points below their measured coverage. These 8 are what is left.
#
# The guard exists to stop the number growing silently. A newly published crate fails until
# someone puts it in a gated list or writes a line here; a line for a crate that has since
# been gated ALSO fails, so this file cannot drift out of date.
#
# Removing a line -- by measuring the crate and gating it -- is the point. Adding one should
# feel like debt.
